# rtl8153: Realtek RTL8153 / RTL8153B / RTL8153C

Directory: `src/drivers/rtl8153/` · `0bda:8153` and the adapters built on it ·
USB gigabit Ethernet

The `cdc` driver ([cdc.md](cdc.md)) plus the Realtek part, as for the RTL8156
([rtl8156.md](rtl8156.md)): a different chip, with a gigabit PHY. The Realtek
registers and PHY window are shared with rtl8156 in `src/drivers/common/realtek/`.

**Written without the card (2026-11-04).** Not yet run on hardware.

## How it works

1. The card is switched to its CDC ECM configuration. Its own firmware then runs
   the MAC, as Linux's `cdc_ether` drives `0bda:8153` when `r8152` is absent.
2. The chip version is read (`PLA_TCR0 >> 16 & 0x7cf0`): 0x5c00-0x5c30 RTL8153,
   0x6000 / 0x6010 RTL8153B, 0x6400 RTL8153C.
3. The PHY is told over Realtek vendor requests what to advertise, gigabit at
   most: the RTL8156's 2.5G register does not exist on this chip and is left
   alone.
4. Frames go through the `cdc` transport, ECM (NCM if the card has it and it is
   asked for).

Matched ids: Realtek `0bda:8153`, and the RTL8153 adapters of Linux r8152's table:
Microsoft `045e:07ab`, `07c6`, `0927`, `0c5e`; Samsung `04e8:a101`; Lenovo
`17ef:304f`, `3054`, `3062`, `3069`, `3082`, `3098`, `7205`, `720c`, `7214`,
`721e`, `a387`; Linksys `13b1:0041`; Nvidia `0955:09ff`; TP-Link `2357:0601`;
D-Link `2001:b301`; ASUS `0b05:1976`. An id among them whose chip is of the RTL8156
family still runs, with its 2.5G register.

On a running console, as for rtl8156:

```sh
tools/xectl.py advertise 1000|100|default
tools/xectl.py phy 0xa400 [value]
tools/xectl.py reg pla|usb 0xe610 [value]
```

## Issues

- **Not run on hardware yet.** Open: whether the firmware advertises gigabit in
  CDC mode by itself (the RTL8156B's offered 10/100 only), and whether every
  adapter in the list has a CDC ECM configuration (`cdc_stats` step and
  `rtl_stats` chip version say how far a card got).
- At most what the console's USB carries, as every card: about 28 MB/s in and
  24 MB/s out (see [xedrivers.md](../xedrivers.md)).
